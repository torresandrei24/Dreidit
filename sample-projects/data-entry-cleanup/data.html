Data Entry & CRM Cleanup — Sunrise Travel Co.

A role-play client brief: a week of messy agent notes — phone calls, emails, and sticky notes — turned into a CRM-ready client tracker. These are the accuracy rules an owner can trust.

Client Brief (as given to me)

ClientSunrise Travel Co. (US/Canada clients)
Task10 messy leads → clean tracker
Data sourcesCall log · emails · agent sticky notes

The 8 Accuracy Rules I Work To

  • ✓ Don't guess. Missing info stays blank — never invent numbers, emails, or dates.
  • ✓ Dates always as YYYY-MM-DD; unknown year left blank, never assumed.
  • ✓ US/Canada phones formatted as +1 (XXX) XXX-XXXX; incomplete numbers flagged.
  • ✓ Names cleaned to title case ("KEVIN TAN" → "Kevin Tan").
  • ✓ Trip type from a fixed list only — closest fit, never invented.
  • ✓ "N/A" and "none" become blank cells, not words.
  • ✓ One row per lead. Duplicates merged into one entry.
  • ✓ Notes column = only what agents need: requests, budget, "do not call", pending items.

"Note 5: walk-in — older couple, no booking yet, names not taken" ▲ Flagged: not entered — no lead data. Nothing to chase.

How I Report Back (part of the job)

  • Number of leads entered, duplicates merged, and items flagged for missing critical info
  • The two messiest things in the source notes — so the owner can fix the process
  • One short, human message — not a wall of text
